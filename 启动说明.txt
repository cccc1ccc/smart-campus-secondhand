Campus Loop 校园二手交易平台 —— 启动说明
==========================================

一、怎么打开
------------
1. 双击本目录下的 "Open Campus Loop.bat"（或 "start.bat"）。
2. 会弹出一个黑色命令行窗口，几秒后自动打开浏览器：http://localhost:8080
3. 命令行窗口就是服务器，**关闭这个窗口 = 停止运行**。

二、第一次启动
--------------
不需要安装数据库。首次启动会在本目录下生成 data 文件夹（内置 H2 数据库），
并自动写入 16 个学生账号、5000 条商品、8 条求购信息，大约 5 秒钟完成。
想恢复出厂数据：关掉窗口，删除 data 文件夹，再双击启动即可。

四、运行环境
------------
需要 Java 17 或更高版本（本机已装 JDK 25，可直接用）。
检查方法：命令行执行 java -version。

五、端口被占用怎么办
--------------------
默认端口 8080。若被别的程序占用，可以在命令行里先执行：
    set APP_PORT=8090
再执行 start.bat，然后访问 http://localhost:8090

六、想要一个桌面快捷方式
------------------------
右键 "Open Campus Loop.bat" → 发送到 → 桌面快捷方式，
再把桌面上的快捷方式改名成 "Campus Loop" 即可。
（也可以右键 → 创建快捷方式，同样效果。）

七、常见问题
------------
Q: 双击后窗口一闪就没了？
A: 说明 Java 没找到，或端口被占用。窗口里会打印 [ERROR] 原因，按提示处理。

Q: 想用 MySQL 8 而不是内置数据库？
A: 先建库：CREATE DATABASE secondhand CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   再执行：mvn spring-boot:run -Dspring-boot.run.profiles=mysql
   数据库账号密码用环境变量 DB_USER / DB_PASSWORD 指定（默认 root/root）。

Q: 想要源码和完整文档？
A: 见 README.md 第 11 节，以及 docs/RELEASE_v1.0.md。
